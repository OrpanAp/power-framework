Routing & middleware

Build endpoints with HTTP methods, named parameters, middleware chains, and route groups.

Define routes

Route definitions live in app/routes/*.js. Handlers can be synchronous or async. 

export function webRoutes(app) {
  app.get('/', HomeController.index);
  app.post('/login', auth.requireGuest, authLimiter, AuthController.login);
  app.get('/users/:id', async (req, res) => {
    const user = await User.find(Number(req.params.id));
    if (!user) return res.status(404).json({ error: 'not found' });
    res.json(User.serialize(user));
  });
}

Supported methods include get, post, put, patch, delete, head, options, and all. Named path parameters such as /users/:id are available on req.params.

Middleware

app.use(securityHeaders(config));
app.use('/admin', requireAdmin);
app.post('/login', limiter, AuthController.login);

Middleware either sends a response, calls next(), or passes an error with next(err). Order matters: each middleware runs in sequence.

Route groups

app.group('/admin', [auth.requireRole('admin')], (r) => {
  r.get('/', AdminController.dashboard);
  r.get('/users', AdminController.usersIndex);
  r.delete('/users/:id', AdminController.usersDestroy);
});

Request and response helpers

API Purpose
req.params Named route parameters
req.query Parsed query string
req.body Parsed JSON or URL-encoded body
req.session Server-side session methods
res.render(view, data) Render a template
res.json(obj) Send JSON
res.redirect(path) Redirect to a local path
Request bodies support JSON and URL-encoded forms. Multipart file uploads are not currently provided by the framework.
