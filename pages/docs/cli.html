POWER 2.0 · NODE.JS ≥ 22.13

CLI reference

Use the built-in command line to serve the app, generate code, inspect environment settings, and manage database migrations.

Command format

node bin/power-cli.js help
node bin/power-cli.js serve

Project and server

Command What it does
init [dir] Scaffold a project and create environment defaults.
serve [--port=3000] Start the development server.
make:controller Name Generate a controller.
make:model Name -m Generate a model and migration.
make:migration name Create a timestamped migration.

Database commands

node bin/power-cli.js db:migrate
node bin/power-cli.js db:rollback
node bin/power-cli.js db:status
node bin/power-cli.js db:seed
node bin/power-cli.js db:check

Environment and secrets

node bin/power-cli.js env:check
node bin/power-cli.js env:check --env=production
node bin/power-cli.js env:get APP_NAME
node bin/power-cli.js env:set APP_NAME="My App"
node bin/power-cli.js env:example
node bin/power-cli.js key:generate --write

Account utilities

node bin/power-cli.js admin:info
node bin/power-cli.js user:reset-password
node bin/power-cli.js user:disable-2fa user@example.com

Use node bin/power-cli.js help as the source of truth for the checked-out version. Run npm test to execute the automated test suite.
